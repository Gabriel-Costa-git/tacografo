# Tacógrafo (`tg`)
Livro-razão, freio de orçamento e status derivado da orquestração Maestri, alimentado por hooks do Claude Code. python3 stdlib + JSONL + 5 hooks; sem daemon, sem porta, sem dashboard.
- Desenho aprovado: `docs/desenho.md` · organograma: `docs/organograma.json` · auditoria: `docs/auditoria.md`
- Contrato de implementação F1 (leia antes de codar): `docs/CONTRATO.md`
- Contrato provado dos hooks (sonda F0): `docs/sonda/`
- Testes: `python3 -m unittest discover -s tests -v`
